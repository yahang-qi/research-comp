# research-comp

Code for the research comprehensive exam of Yahang Qi.

- [`reproduction/`](reproduction/) contains reproduction and additional analyses of [Estimating Individualized Treatment Rules Using Outcome Weighted Learning](https://doi.org/10.1080/01621459.2012.695674) by Zhao et al. (2012).
- [`extension/`](extension/) contains the simulation study for the extension to text treatments described in the report.
